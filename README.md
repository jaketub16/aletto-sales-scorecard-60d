# Aletto Sales Scorecard · last 60 days (Sep 11 to Nov 9, 2026)

Self-contained HTML web deck (`index.html`). Arrow keys / space to navigate, N for speaker notes, `?static` for no animation.
Built by `build.py` (+ `data.py`, `js.js`, `css.part`, `extra.css`, `drill/`) from the read-only scorecard JSON exports.

26 slides: the 19 scorecard slides plus 7 drill-down lists (no-shows, confirmation reach, Scopes not held, cancels, qualified-no-Scope, blank fields, objections).
Prospects are shown as first name + last initial only. No company names, emails or phones. Names, companies, emails and phones inside quotes are replaced with [name] / [company].
Links go to GHL and Fathom, which need a login.
